📖 Guide de Configuration & Dépannage

1. Autoriser le smartphone à joindre Ollama sur votre PC Windows :

Par défaut, Ollama écoute uniquement sur 127.0.0.1. Pour l'ouvrir à votre Galaxy S25 Ultra sur le même réseau WiFi, lancez une invite de commandes sur le PC :

set OLLAMA_HOST=0.0.0.0
set OLLAMA_ORIGINS=*
ollama serve

2. Exécuter Ollama directement sur votre Samsung Galaxy S25 Ultra :

Avec le processeur Snapdragon 8 Elite du S25 Ultra, vous pouvez faire tourner des modèles 3B à plus de 25 tokens/s en local dans Termux :

pkg install ollama
ollama serve &
ollama run llama3.2:3b

L'adresse dans la PWA sera alors directement http://127.0.0.1:11434 !

3. Edge Gallery / PocketPal AI sur Android :

Dans l'application Edge Gallery ou PocketPal, cochez l'option « Start Local API Server ». Elle fournira une API compatible OpenAI sur le port 8080.
