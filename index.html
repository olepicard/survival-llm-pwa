📖 Guide d'Installation Hors-Ligne & Moteurs

1. Sur Smartphone Android (Samsung S25 Ultra) :

Le processeur Snapdragon 8 Elite et ses 12 Go de RAM permettent d'exécuter localement des modèles 1B à 3B sans aucune connexion :

  • Option Termux (Ollama) : Téléchargez Termux depuis F-Droid, tapez pkg install ollama, puis lancez ollama run llama3.2:1b. L'adresse est http://127.0.0.1:11434.
  • Option llama-server : Compilez ou téléchargez le binaire llama-server ARM64 de llama.cpp avec support Vulkan pour exploiter le GPU Adreno 830.
  • Option PocketPal AI : Installez l'APK PocketPal AI, chargez un modèle GGUF et cochez « Start Local API » sur le port 8080.

2. Sur PC Windows connecté au Smartphone (WiFi / Hotspot) :

Si vous souhaitez faire tourner un modèle plus lourd (ex: 8B ou 14B) sur votre PC et l'interroger depuis le smartphone :

set OLLAMA_HOST=0.0.0.0
set OLLAMA_ORIGINS=*
ollama serve
