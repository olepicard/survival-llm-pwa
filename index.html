📖 Guide des Moteurs IA

1. Mode WebGPU Embarqué (Recommandé par défaut) :

Ce mode utilise directement le processeur graphique de votre smartphone ou PC (comme l'Adreno 830 du Galaxy S25 Ultra). Il ne nécessite aucun terminal, aucun Termux, et aucune application externe. Le modèle se télécharge une fois dans le cache et fonctionne à vie en mode avion.

2. Mode Ollama / llama.cpp Natif (Pour utilisateurs avancés) :

Si vous souhaitez faire tourner un modèle plus lourd (3B ou 7B) avec les performances C++ maximales, installez Ollama dans Termux sur Android ou sur votre PC Windows partagé sur le WiFi local (avec set OLLAMA_HOST=0.0.0.0).
